# 知识图谱卡顿修复

## 原因与实现

实际数据库的完整网络为1060节点、1100关系。旧版本每条关系绘制两条路径、一个带滤镜的光点及无限循环 `animateMotion`；每个节点还有旋转轨道、模糊光晕、核心与高光。边和节点事件绑定还反复使用 `nodes.find`，导致额外遍历。展开后的每次鼠标/滚轮事件都会立即更新SVG视口。

改为独立的 `frontend/graph-renderer.js`：

- 静态原生SVG，无力导向持续仿真，无SMIL及逐节点循环动画，不添加外部依赖。
- 节点和邻接关系用Map索引；边按源节点类型合并为少量path；所有1060节点和1100关系仍保留。
- 使用紧凑、确定性的布局，避免旧版本随节点数线性增长的巨大同心环。
- 标签按视口和缩放级别显示：全网概览最多18个，放大最多100个；小图最多70个。悬停/键盘聚焦时显示完整节点名称与直接关联边。节点本身均保留aria标签和键盘操作。
- 点击/键盘事件在容器委托，不逐节点创建处理器。
- 视口与标签更新使用requestAnimationFrame合并事件；静止时无绘制循环，隐藏后不进行标签绘制。
- 保留原SVG接口，因此展开、移动、缩放、查询网络、节点卡片、知识点工作台和证据面板继续使用原入口。

## 本机前后对比

在本地真实浏览器、同一完整数据集，调用renderGraph后采集30次requestAnimationFrame间隔。数字是本次实测，不是跨设备保证。同步渲染耗时不含HTTP请求。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 节点/关系 | 1060/1100 | 1060/1100 |
| 图谱DOM元素 | 13095 | 4273 |
| 持续的边动画 | 1100 | 0 |
| 同步renderGraph耗时 | 218.5 ms | 23.0 ms |
| 平均帧间隔 | 348.0 ms | 15.6 ms |
| 本次最大帧间隔 | 627.2 ms | 17.6 ms |

图谱计数和诊断可读取 `MathGraphRenderer.stats`。完整图谱的后续绘制复测约35ms，耗时会随界面状态变化。标签使用屏幕坐标包围盒避免相互重叠。检查JS语法和git diff空白，并在完整图谱上实操展开、放大、拖动、显示全部、键盘打开叶戈罗夫定理节点，以及进入知识点工作台。未修改数据库或删减图谱关系。

完整1060节点上额外验证：鼠标缩放386%、拖动、点击叶戈罗夫定理，以及390px手机布局。允许在节点上开始拖动，只有移动超过阈值才捕获指针，因此不会因节点密集而无法平移；单击仍打开卡片。空闲状态没有待绘帧或持续图谱动画。

## 星系分层导航（2026-10-22）

新增 `graph-taxonomy.js` 和 `graph-galaxy.js`：首页显示7个学科星系，点击进入主题，再进入最多36个知识点的局部网络；面包屑可随时返回。静态星尘、星云与核心光晕恢复宇宙外观，无持续仿真或逐边动画。星系之间仅汇总数据库已有跨组关系，不推断前置关系。

默认根据已有领域与关键词生成导航分组，不标为AI结果。进入4–180节点主题后可调用DeepSeek细分。`POST /graph-navigation/suggest`校验ID完整性、去重和未知ID，遗漏节点保留为尚未归类；结果标记AI分类草案，仅在当前视图中保留，不写入知识或关系数据库。API不可用时保留原视图。

本机实测：完整数据1060节点逐层遍历后每个ID恰好出现一次，1100关系原数据保留。根视图7星系同步渲染约3–6ms，数学分析15主题约9–11ms，空闲无待绘帧和SMIL。桌面实操进入数学分析、测度主题、点击叶戈罗夫定理、面包屑返回及全屏内继续分层；390px布局无横向溢出，另提供可读的主题按钮。分类与API校验单元测试通过。

真实AI按钮请求本次返回503（服务暂不可用），已验证失败提示和保留原分类；未将模拟测试作为真实AI成功证据。上述旧版与静态全网性能表是此前同规模全网测试，新的默认首页展示汇总星系，二者不是同一可见图元数量。
