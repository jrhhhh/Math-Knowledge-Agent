## 参考与设计依据

参考 [MathBox](https://github.com/unconed/mathbox) 的交互数学可视化思路，以及 [Interactive Linear Algebra](https://github.com/QBobWatson/ila) 的矩阵几何教学方式。精确计算采用 [SymPy 矩阵文档](https://docs.sympy.org/latest/tutorial/matrices.html) 的方法。未将这些项目描述为已安装的 GitHub skill，也未复制其代码或引入 WebGL 依赖。实现时使用本地 invariant-computation skill 的对象表示、计算边界和交叉校验原则。

## 计算表示与边界

矩阵输入是有限阶有理数矩阵，字符串只接受整数、小数和分数；小数按十进制精确转为有理数。符号计算在本地后端完成，模型不生成数值。图形坐标、特征值近似和矩形和使用浮点数。每次计算在独立子进程中运行，12 秒超时，避免复杂符号运算阻塞服务。

表达式采用 AST 白名单解析，不执行用户代码。支持 x、pi、e、四则运算、受限幂和列出的单参数函数；不支持任意 Python/SymPy 指令。tan/cot/sec/csc 的参数支持 a*x+b；可进行多项式组合，嵌套对数、根式或倒数组合明确拒绝。周期奇点在有界区间内检查，图形不会跨越奇点连线。

此实验处理实数连续区间上的普通定积分，不把跨奇点的积分当成反常积分。定义域端点不报告双侧导数。Abs 在尖点处显示不可导。原函数在各连续分支使用，需加任意常数 C。未求出显式原函数时保留符号/数值积分结果，不冒充初等原函数。

二维矩阵展示变换后的网格、单位正方形、v 与 Av 及实特征方向；没有实特征方向时明确提示。更高阶矩阵展示复平面上的特征值，不将高维变换伪装成二维投影。全部主子式按相同的行列索引取子矩阵；顺序主子式为前 k 行、前 k 列。正定判据仅用于实对称矩阵。

## 验证

后端用精确值案例覆盖多项式、双侧不可导、定义域端点、积分上下限反向、跨奇点、非初等原函数、周期函数、精确分数、复特征值、Jordan 块、奇异矩阵与四阶全部 15 个主子式。交叉检查迹等于特征值之和、行列式等于特征值之积以及 Cayley–Hamilton。
