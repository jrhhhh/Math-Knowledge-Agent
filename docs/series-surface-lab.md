# 级数与二元函数实验

实验区一级分类为「数学分析」「高等代数」。数学分析下设「导数」「积分」「级数」「二元函数」四个子版块，切回数学分析时恢复上一次选择。新增「级数」「二元函数」实验，使用现有本地数学服务，不调用模型生成计算数值。

## 级数

支持几何级数、p级数、交错p级数和指数函数Taylor级数，观察项数1–300，可调整公比、p或展开参数。蓝线显示部分和、橙点显示通项；收敛时显示极限参考线、有限项误差，交错p级数额外显示下一项余项界。几何级数从n=1开始，首项1；指数级数的第n项为x^(n-1)/(n-1)!。

标准级数判别结论依据对应参数条件，有限项图像不构成收敛证明。和与误差为浮点近似。

## 二元函数

预设抛物面、马鞍面、高斯曲面、波纹和圆锥面，也可输入安全解析的f(x,y)。SVG曲面支持拖动旋转、滚轮缩放、键盘/滑块调整视角和重置视角。可调整绘图区间以及观察点，查看函数值、偏导表达式与该点双侧偏导数。

默认31×31实数网格；非实数或未定义采样点留空，并保留原表达式的定义域限制，例如x/x在x=0仍不绘制。z轴独立缩放，网格图不代替连续性、可微性或极值证明。图中P标记只在观察点落入绘图范围时显示。

## 接口和边界

- `POST /math-lab/series`：`kind`、`n`、`parameter`。
- `POST /math-lab/surface`：`expression`、`radius`、`x`、`y`、`resolution`，以及系数 `a`、`b`（默认1）。
- 表达式复用AST白名单解析；禁止代码执行及过大幂。表达式长度最多180字符，AST最多64节点。
- 每次计算独立进程，沿用12秒超时；曲面半径0.2–100，观察点坐标−100–100，系数接口范围−100–100（UI滑块−10–10），网格分辨率15–41。
- 新增参数不改变原导数、积分和矩阵接口。切换页签或更新参数会使旧请求失效。

验证：`cd backend && .venv/bin/python -m unittest tests.test_math_lab_extra tests.test_math_lab -q`，共16项通过，覆盖判别边界、交错余项、300项Taylor稳定性、曲面函数值/偏导、定义域空洞、不可导点和非法输入，以及原有微积分、矩阵实验。实际浏览器检查级数、曲面、视角调整、马鞍面预设及手机布局；数值图示不声称独立定理证明。

## 参数交互与失败恢复

参考 Desmos 官方滑块文档（https://help.desmos.com/hc/en-us/articles/202529069-Sliders-and-Movable-Points-in-a-Graph），曲面支持 `a*x^2+b*y^2` 等带系数表达式及 a/b 滑块。级数参数范围扩至 −10–10（p 必须严格大于0）。

输入采用700ms防抖。等待更新或输入无效时保留上次有效结果，并通过状态文字和图框虚线明确标注；清空字段不会默认为0，越界会显示允许范围。请求序号避免旧结果覆盖新参数。切换实验清空旧图，避免跨类型混淆。

微积分接口新增可选 `graph_on_invalid_observation`（默认 false，保留已有 API 行为），前端启用后，观察点不在定义域、h=0、积分区间跨奇点时返回当前函数采样及 warning，不返回无效切线或积分结果。二元函数观察点未定义不影响有效区域绘图。符号计算仍有12秒限制；超时时保留并标记旧图，复杂表达式可能需要简化。

曲面预设的系数控件随函数变化：抛物面/马鞍面使用两个方向的二次项系数；高斯曲面为 a*exp(-b*(x^2+y^2))，a 为峰高、b 为集中程度（UI 最小0.1）；波纹为两个方向频率；圆锥只含斜率 a。切换预设重置系数为1；自定义表达式按完整标识符识别 a/b，无系数时隐藏整个控件区域，abs 等函数名不误判为参数。

## 自定义级数

级数示例新增「自定义级数」，输入从 n=1 开始的通项（例如 `1/n^2`、`(-1)^(n+1)/n` 或 `sin(n)/n^2`）。可选数值参数 p，仅当表达式使用 p 时显示参数输入。接口 kind=custom，增加 expression 字段，仍限制1–300项和180字符，沿用安全 AST 与12秒进程超时。支持整数指数的负数底数以表达交错项。

逐项计算并校验原始定义域；未定义、非实数、溢出会指出具体项号，部分和溢出也明确报错。不会跳过坏项后继续求和。自定义结果的 converges、limit、error、remainder_bound 为 null，不显示无限和参考线，也不自动断言收敛。浏览器检查默认通项、交错项、p参数与未定义第2项错误恢复；后端测试覆盖数值、原始定义域空洞和非法输入。

导航已扩展：数学分析下仍为导数、积分、级数、二元函数；Taylor、函数列、路径、梯度通过各自分类内的实验选择器进入。高等代数下为矩阵变换、方程组、二次型、分解与迭代。新增实验的接口与计算边界见 [math-lab-exploration.md](math-lab-exploration.md)。
