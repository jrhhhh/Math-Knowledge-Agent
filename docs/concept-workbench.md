# 知识点工作台与上下文衔接

## 使用

图谱中打开已保存知识点卡片，点击“进入学习工作台”。主区域显示已保存知识说明、数据库直接关联的教材片段、关联知识、相关笔记和当前对话的最近回答；侧栏保留问题草稿及显式选用的教材引用。没有额外知识点搜索入口。

- 带入学习对话：把问题放在开头，附上可见、带边界标记的知识点上下文；只填入输入框，不自动发送。
- 生成相关习题：复用现有生成器，带入知识点和当前目标（遵守600字限制），不自动调用生成API。
- 整理成笔记：打开原笔记编辑器并填写草稿，用户正常保存后才写入数据库。草稿含稳定的 `[知识点 #id：name]` 标记；仅关键词相似的旧笔记显示“关联待确认”。
- 教材片段：明确选用后才进入提问上下文；可打开原页，也可移除。教材伴读选中的文字会带回当前工作台。未知页码不可点击打开；片段审核不冒充教材整体审核。
- 跨页面顶部显示当前上下文，可返回或清除。清除只移除由本功能标记的上下文块，保留问题及用户追加的其他文字；不会删除已有笔记和对话。

工作台状态保存在当前标签页 sessionStorage，支持刷新继续；未审核知识说明、模型回答和数值结果不会被升级为已验证数学结论。直接关联教材显示前8个片段及总数，没有出处时明确留空。异步请求以版本号避免快速切换串入上个知识点的数据，单个资源失败不阻塞其他区域。

## 实操验证

本地真实浏览器，以数据库知识点 #39“叶戈罗夫定理”为入口，测试有限测度下 f_n=n·1_(0,1/n) 的几乎处处收敛、积分不收敛、叶戈罗夫例外集、控制收敛和一致可积性。真实发送问题及严密性追问到新建对话 #51，未修改或删除既有对话。

已检查问题向练习目标、笔记草稿、学习输入的传递；实际回答能给出反例主要结论，但初次回答中“峰值无界因此不存在可积控制函数”与对任意例外集的描述不充分，因此进一步追问要求用共同零测集、g(x)≥1/(2x)和显式 E=(0,δ)补证。真实模型调用不是完整数学正确性证明。

补充实测：笔记实际保存后出现在工作台，标题为 `[验收记录] 叶戈罗夫定理 · 条件与反例`；知识点之间切换后原问题草稿恢复。Hardy 已保存关联片段能进入提问上下文，未登记页码的条目禁止跳页；“清除上下文”删除专属标记块但保留问题。1176px/390px布局无横向溢出，公式无 mjx-merror。当前讨论在工作台独立滚动展示，不用整屏长回答挤走教材和笔记。

最后完成教材原页实操：从已关联的 Hardy 第1页打开伴读，在“本页文字与校对”展开区选中文字，点击引用后，返回工作台可看到相同教材和PDF页码。快速连续切换 Hardy 与叶戈罗夫后，来源数量和知识点标题保持对应，旧异步请求未覆盖新选择。
