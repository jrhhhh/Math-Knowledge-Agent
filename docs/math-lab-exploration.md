# 数学实验导航与新增实验

## 入口

一级学科为数学分析、高等代数，每个学科均有四个二级分类。切换学科恢复上次实验，分类内的实验选择器保留当前选择。

| 学科 | 分类 | 实验 |
| --- | --- | --- |
| 数学分析 | 导数 | 原有割线/切线；Taylor 逼近与误差 |
| 数学分析 | 积分 | 原有定积分与中点矩形和 |
| 数学分析 | 级数 | 原有标准/自定义数项级数；函数列与 ε 误差带 |
| 数学分析 | 二元函数 | 原有曲面与偏导；路径趋近；梯度、等高线与线性平面 |
| 高等代数 | 矩阵变换 | 原有1–4阶方阵性质与二维变换 |
| 高等代数 | 方程组 | 1–4行、1–4列矩阵，精确解集和逐步消元 |
| 高等代数 | 二次型 | 2×2对称矩阵的曲面、等高线、正交主轴和标准形 |
| 高等代数 | 分解与迭代 | 2×2矩阵 SVD 四阶段变换；Aᵏv 轨迹与范数 |

## 接口与依赖

新增 `POST /math-lab/explore`，`kind` 为 `taylor`、`sequence`、`path`、`gradient`、`system`、`quadratic`、`decomposition`。请求模型见 `backend/app/api/math_lab_explore.py` 的 `ExploreInput`。原 `/calculus`、`/matrix`、`/series`、`/surface` 接口保留。

使用现有 AST 白名单、180字符限制与独立子进程12秒超时，不执行用户代码，不调用模型生成数值。新增 NumPy 依赖用于对称特征分解、SVD 与矩阵迭代，已列入 `backend/requirements.txt`。

## 计算边界

- Taylor：最高12阶，展开点须在实数定义域内部，并检查所用阶数的双侧导数。绘制原函数、多项式及独立误差图；“最大误差”为301个采样点上的值，不是严格误差上界，也不声称 Taylor 级数处处收敛。
- 函数列：用户提供 `f_n(x)` 和候选极限，n 在1–300。选择当前整数后再解析有限幂，绘制候选极限的 ±ε 带。网格内全部满足误差要求，只说明当前 n 的采样结果；不自动验证极限函数或一致收敛，可能漏掉尖峰。
- 路径：输入 x(t)、y(t)，检查两侧趋近原点。显示 t=10^-0.1 至10^-8的正侧采样、表格及沿该路径的左右符号极限。该侧缺少有效实数采样时标为未确认。不同路径极限不等可否定二元极限，相同不足以证明存在。
- 梯度：复用曲面原始定义域校验及双侧偏导检查，叠加偏导组成的线性平面，提供等高线及方向角。一般函数未自动证明可微性，只有可微时才能称其为切平面并使用 ∇f·u 得到方向导数。
- 方程组：矩阵和 b 采用精确有理数；保留每次换行、倍乘、消元后的增广矩阵；根据系数/增广矩阵秩区分无解、唯一解和无穷多解，显示精确解集及自由变量数。二元方程显示直线，其余维数使用矩阵和解集，不投影伪装。
- 二次型：必须是2×2实对称矩阵。正负定分类使用精确矩阵；正交矩阵、特征值和图像使用浮点近似。主轴以等高线上的虚线显示，标准形按 x=Qu 给出。
- 分解与迭代：SVD 滑块展示原单位圆、Vᵀ、ΣVᵀ、UΣVᵀ四个阶段，固定等比例坐标范围；正交变换可能包含反射。迭代最多40步，显示轨迹和范数；有限步图像不构成收敛证明。

沿用参数更新防抖、请求序号与取消机制；错误时保留明确标注的上次有效图像，切换实验则清空跨类型旧结果。不会把旧结果当作当前参数的新计算。

### 方程组输入改进

方程组以带未知量 x₁…x₄、加号与等号的逐行系数编辑器输入，支持选择方程数/未知量数。原矩阵和向量字段隐藏保存以兼容现有请求。计算后显示完整的彩色方程，颜色与二维图中直线对应，唯一解标注公共交点；保持精确消元滑块和解集。空项要求填写（无该项填0），不把留空静默解释为0。浏览器验证分数/负数编辑、留空提示、改变未知量数、恢复默认及390px布局。

### 动效与状态反馈

参考 Apple Human Interface Guidelines 的 Motion 指导（https://developer.apple.com/design/human-interface-guidelines/motion），采用短促、可中断的反馈：分段导航滑动高亮、按钮按压、输入聚焦、滑块轨道填充与拖动高亮、分类内容轻量过渡。计算状态由现有请求生命周期显式驱动，区分等待、计算中、成功、条件警告、输入错误；图中状态胶囊自动消退，详细状态文字保留，不显示虚假完成百分比。

结果只做透明度过渡，不对数值曲线或曲面进行数学插值。动态步骤滑块通过事件委托更新反馈，不重建计算请求。遵循 `prefers-reduced-motion`，关闭过渡、旋转与位移动画，但保留状态文字和 `aria-busy`。无新增前端依赖。

### 矩阵编辑与可调面板

矩阵变换、二次型和分解/迭代的输入统一为方括号包围的逐格矩阵编辑器；保留隐藏 textarea 作为接口数据来源。矩阵变换可选1–4阶，二次型和SVD为2×2；二次型非对角元同步，空项明确提示。预设、恢复默认与编辑器保持同步。桌面左侧面板支持拖动分隔条、方向键微调、Home/End到边界、双击恢复320px，并为右侧图形保留最小空间；手机端改为上下布局，分隔条隐藏。导航与资源标题统一为四字“笔记资料”。
