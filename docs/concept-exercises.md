# 知识点出题与习题本

练习区仅提供生成题目、习题本和思路提示，不再提供作答输入、提交、思路审核、人工审核或错题复习工作区。历史作答数据及原有后端接口保留，当前练习界面不加载它们。

## 使用流程

1. 从知识点详情、图谱卡片或练习区选择知识点，设置基础/应用/进阶、1–5题及训练目标。
2. 后端复用现有DeepSeek配置生成题干和参考解答。生成中显示等待耗时，失败后恢复按钮，不以模板替代。
3. 在题组中预览、编辑题目与解答，点击「加入习题本」。题目持久化并关联知识点。
4. 在习题本搜索、切换题目，按需查看思路提示和折叠的参考解答。也可带入学习对话或返回生成区。

全部、待加入、已加入筛选仅表示收藏状态，不表示已完成或掌握。参考材料表示出题背景，不伪造原书题号。生成题目及参考解答仍需核对。

## 接口与配置

- `POST /concept-exercises/generate`：`concept_id`、`difficulty`、`count`、`objective`，返回持久化草稿。
- `GET /concept-exercises/drafts?concept_id=...`：恢复该知识点最近50条草稿和已收藏题目。
- `POST /concept-exercises/drafts/{id}/adopt`：保存编辑后的`title`、`content`、`solution`至习题本，重复请求返回已有题目。
- `GET /problems/`：习题本题目，含参考解答及生成来源元数据。
- `POST /concept-exercises/problems/{id}/hint`：优先返回已收录且审核通过的一级提示；否则调用DeepSeek给出一个切入点及引导问题。提示请求只发送题目，不发送参考解答或学生作答，也不更新学习判断。

使用现有后端`.env`中的`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`；密钥不传到浏览器。草稿使用`concept_exercise_drafts`表，后端启动时自动创建。
