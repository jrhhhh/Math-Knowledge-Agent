# Math-Agent 产品升级与逐项验收

日期：2026-10-09。依据本次产品评审实施，保留蓝白液态玻璃视觉风格。

## 工作规则

- 每项功能完成后先做接口/数据验证，再通过电脑上的真实浏览器操作验收；验收通过后才进入下一项。
- 使用独立验收数据库，避免测试题、作答、笔记影响个人知识库。
- 保留已有 API 默认行为、DOM ID 与历史数据；新增交互按学习任务组织。
- 验收记录包括操作、可见结果、限制与截图；未验证的项目不得标为完成。

## 完整范围

1. 统一学习工作台：分区导航；讲解/提示/检查解答；题目和草稿跨模式延续；管理工具独立。状态：已通过首轮验收。
2. 结论与证据：关键步骤关联真实来源或工具证据；清晰区分模型审查、结构检查、受控计算与形式验证。状态：已通过首轮验收。
3. 作答反馈：学生提交、审核工作区、错误定位、修订重交、审核状态与下一步建议。状态：已通过首轮验收。
4. 错题与间隔复习：错误归档、复习排程、延迟重测、完成记录与当前掌握状态分开。状态：已通过首轮验收。
5. 图谱学习路径：按前置关系定位补学路径；关联练习；解释推荐原因。状态：已通过首轮验收。
6. 学习成果沉淀：保存解释为笔记、编辑、收藏、课程归档与导出；保留来源和验证范围。状态：已通过首轮验收。
7. 教材导入与阅读：上传 PDF、校对文本/公式、章节与审核状态、原页阅读、选段提问。状态：已通过首轮验收。
8. 数学交互可视化：导数/积分/线性变换的交互图示、参数与适用条件。状态：已通过首轮验收。
9. 产品效果评估：学习闭环、反馈等待、重测与回访等可追溯统计；无数据时不虚构结果。状态：已通过首轮验收。

## 范围约定

当前交付是本地个人数学学习产品。多用户账号隔离仅在开放多人部署时作为前置项，不在本轮擅自增加账号体系。
教材出处只能来自实际导入内容，工具证据只能由真实执行生成；模型评审不等同于数学正确性证明。
