日期：2026-10-11。按用户要求，先修正实验区两个下拉菜单的箭头，再提交此前改动（`2895ee7f38eebca40a82540cf2acda552dc85f52` 已推送 main），随后实现独立教材伴读栏目。本记录对应可行性方案 A–C；D 阶段内容增强未纳入第一版。

## 使用

1. 打开导航栏“教材伴读”，选择已有资料或“导入 PDF”（50 MB 内、1–1000 页）。桌面上的整本《最优化导论》第四版已作为日常资料导入。
2. 用原 PDF 目录、页码回车、连续滚动和书签阅读，缩放可选适合宽度或比例。桌面拖动中间分隔条，键盘方向键也可调整；手机切换“阅读教材 / 伴读对话”。
3. 默认提问范围是当前页。拖选原页文字自动引用选段；翻页不改变已锁定选段。也可从折叠的“本页文字”选取或指定连续 1–10 页（最多 30000 字）。
4. 自由提问或选择解释、推理、例子、提示。讨论可连续追问、保存、新建及切换；生成中可停止。回答中的“查看原页”返回引用位置。
5. 保存为笔记后，在笔记的原始依据中查看保存时的来源文本与版本，并打开原页。校对教材不会覆盖历史回答和笔记的依据快照。
6. “生成练习草稿”保留教材来源。编辑并核对题目与参考解答，勾选确认后加入既有练习区；再按现有作答审核和复习流程使用。

## 实现范围

- 原有无构建前端 + 独立 ES 模块 + FastAPI，未迁移 React/Node 或改变原问答接口。
- 本地部署官方 `pdfjs-dist 6.3.289` 的阅读器、worker、CMaps、字体与 WASM，保留 Apache-2.0 与字体许可。`pdf-reader-vendor.css` 从发行版 CSS 生成，使用 `@scope (#crPdfContainer)`，并把 `:root` 变量移至 `:scope`，避免 `.sidebar` 等通用选择器污染应用。
- 新增 schema 11 的四张表：`course_reading_states`、`course_conversations`、`course_messages`、`course_exercise_drafts`。模型回复保存结构化页范围、审核状态、原文本与 SHA-256 版本。
- `/course-reader/books/{id}/state`、`/conversations`、`/conversations/{cid}`、`/conversations/{cid}/messages/stream`、`/messages/{mid}/note`、`/drafts`、`/drafts/{did}/approve`。
- 服务端验证教材、会话、片段归属、页范围、选段与已保存文本一致性。每个讨论独立控制生成并发，取消不保存完整回答。历史对话上下文有长度上限，教材文字不作为系统指令。
- 练习草稿核对、笔记来源与原有功能复用；模型讲解保持未获数学验证。没有将翻页或生成次数记为学会。

## 已知边界

pypdf 文本层提取不是数学 OCR。该真实教材存在上下标、箭头、汉字等提取错误；关键公式需对照原页校对，选文与保存文本不一致时会提示从“本页文字”选择或先校对。没有把未校对内容自动改为已审核。

这本 PDF 的部分内嵌目录本身存在偏差：例如“5 微积分基础”指向 PDF 第 48 页，pypdf 同样解析为第 48 页，而此页正文属于前一章。阅读器沿用原 PDF 目标，并提示可以使用页码、自建书签和印刷页码偏移校准；没有猜测或改写原文件目录。

大书导入采用后台线程提取文字，上传进度与提取阶段分开显示；仍需保持页面打开，不是可恢复的任务队列。没有做统一的性能基准、教学效果或多用户权限测试。原 PDF、文本与阅读数据在本地保存，但选定范围提问会发送到已配置模型供应商；不是全离线模型产品。备份须同时覆盖数据库和上传目录。
